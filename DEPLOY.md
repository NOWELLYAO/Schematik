# GitHub + Vercel deployment

1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Import the repository into Vercel.
4. Keep the framework as Next.js and use the repository root.
5. For AI, add `AI_GATEWAY_API_KEY` and optionally `AI_MODEL`.
6. Deploy.

Every push to the connected Git branch can trigger a new Vercel deployment.

The core schematic engine works without the AI key.
